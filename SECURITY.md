# Security Policy

Axmol Examples is an educational project. It is not a product and comes with no support guarantee, but security reports are welcome and will be handled on a best-effort basis.

## Supported versions

Only the latest commit on the default branch is maintained.

## Reporting a vulnerability

Please report vulnerabilities privately instead of opening a public issue:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability** and describe the problem, how to reproduce it, and its impact.

You can expect an acknowledgement within a few days. Once the problem is understood, a fix is published and the report is closed.

## Scope

This policy covers the code in this repository. Problems in the [Axmol Engine](https://github.com/axmolengine/axmol) itself should be reported to its maintainers.
